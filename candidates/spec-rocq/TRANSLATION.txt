======================================================================
1. TYPES CHOSEN
======================================================================

Byte: `byte` from Corelib.Init.Byte (the standard library's native byte type,
256 constructors x00..xff).
  - Replaces "U32 plus a proof that it is <= 255" (agreed deviation).
  - Comes with the standard bit view (Byte.of_bits/to_bits, least
    significant bit first) used by bit8_value, and with the standard numeric
    view (Byte.to_N, Byte.of_N with library lemmas of_to_N, to_of_N,
    to_N_bounded), so a bridge file can relate it to WasmCert linear-memory
    bytes (CompCert Byte.int: Z with a range proof) by
    Byte.repr (Z.of_N (Byte.to_N b)) and back, without the spec importing
    WasmCert or CompCert.
  - Decidable, structural equality (Byte.eqb, or destruct): no proof
    irrelevance needed when comparing byte lists.

Code point: `U32`, an inductive with one constructor `U32_bits` of 32 bool
fields b0..b31, least significant first.
  - This is exactly Bend's representation U32{Word(32n)} (Word stores the
    least significant bit first), so u32_byte4 is a plain pattern match,
    u32_byte4_bits is a verbatim translation, and there are exactly 2^32
    values (encoding of a value above U+1FFFFF is None; nothing above 2^32
    exists).
  - No range proof inside the type: U32 constants and the 32-bool
    constructor need no proof terms, and equality of code points and of
    Text is structural (no proof irrelevance).
  - For later use: U32_to_N gives the unsigned value, U32_of_N gives the
    value mod 2^32.  A bridge to WasmCert i32 values (CompCert Int.int) can
    use U32_of_N (Z.to_N (Int32.unsigned v)), or compare bits with
    Z.testbit, both outside this file.
  Rejected: N with no bound (u32_byte4 would have to truncate, so encoding
  of 2^32 + 0x41 would be Some [x41]); a record {n : N; n < 2^32} (every
  constant, and the 32-bool construction in u32_byte4_bits, would need
  proof terms in the spec, and equality would need proof irrelevance);
  Vector.t bool 32 (awkward to pattern match).

Text: `Text := list U32`.  Bend's String is SNil/SCon of Chr{U32}: a list of
code points with no scalar-value restriction.  The Chr wrapper is dropped
(Text is a list of U32 directly).  Rocq's string/ascii types are not used.
Bend string `++` is list `++`; "" is []; a string literal such as "AB" is
written [U32_of_N 65; U32_of_N 66].

Propositions: Bend's Type-valued propositions become Prop.
  Exists(T, x => P) -> exists x : T, P
  Or(A, B)          -> A \/ B
  A & B (props)     -> A /\ B
  A -> Empty        -> A -> False
  Empty             -> False
  Unit              -> (only in all_buffers_bytes, dropped)
  {a == b : T}      -> a = b
  law with `for x: T` premises -> Definition name : Prop := forall x : T, ...
  (+/- quantities, &1/&2 levels: no counterpart, ignored.)
Maybe<.., A> -> option A.  List<&2, A> -> list A.  Data tuples (A & B) of
values -> Rocq products A * B.

Names: Bend `f.g` -> Rocq `f_g`.  One clash: the def decodes_first.nonempty
and the law decodes_first_nonempty; the def is named
decodes_first_nonempty_case (the law keeps its name).

======================================================================
4. DEVIATIONS AND JUDGEMENT CALLS
======================================================================

Agreed deviations applied: native byte type (and the drops it implies);
Text as a list of code points; Prop connectives; streaming laws over an
abstract Decoder; Decoder_correct added.

[D1] bit8_value returns `byte` (Bend: a U32 0..255 with higher bits zero).
  It is built with Byte.of_bits from the bits, least significant first,
  mirroring Bend building the Word directly from the bits.  The shape
  functions consequently return bytes (option byte, option (byte * byte),
  ...) and encoding returns option (list byte).

[D2] bit8_value_sum: Bend compares U32 values using U32 arithmetic; the
  Rocq law compares Byte.to_N (bit8_value ...) with the same sum computed
  in N (with N.b2n for Bool.to_u32).  No overflow is possible in either
  (the sum is at most 255), so the meaning is the same.

[D3] bit8_value_word: Bend's independent check goes bits -> Word(8n)
  (least significant bit first) -> Nat (Word.to_nat) -> U32
  (U32.from_nat).  Rocq: bits -> list bool [b0; ...; b7] (least
  significant first) -> N (Ascii.N_of_digits, the stdlib's
  least-significant-first binary reading, same recursion as Word.to_nat)
  -> byte (Byte.of_N).  Since Byte.of_N is partial, the law reads
  Some (bit8_value ...) = Byte.of_N (Ascii.N_of_digits word).  The check
  stays independent of bit8_value's definition (Byte.of_bits and
  Byte.of_N are separate tables in the stdlib).

[D4] Comments "Returns Some U32 representing the byte" / "Returns two U32
  representing the two bytes" etc. reworded to "Returns Some byte" / "the
  two bytes".

[D5] decodes_examples: byte lists are written with the byte constructors
  in hex (x41, xc2, ...) instead of decimals; the "Bytes in hex" comment is
  reworded into a hex = decimal table for the same values.  Text literals:
  "" -> [], "AB" -> [U32_of_N 65; U32_of_N 66], "A" -> [U32_of_N 65],
  "H" -> [U32_of_N 72]; code points in code_point_to_string(...) keep the
  decimals of LAWS.bend (169, 8364, 128512) via U32_of_N.

[D6] Decoder record fields keep the Bend names: DecodeState,
  decode_start_state, decode_buffer (State -> list byte -> State * Text,
  no `valid` argument), decode_done.  All streaming definitions and laws
  take the decoder D as an explicit first argument.  The comments that
  described UTF8.decode_buffer(state, buffer, valid) and `decoded`'s
  signature are reworded accordingly.

[D7] The comment "`feed` can't match on its erased proof, so it takes the
  proof apart with these." is dropped with all_buffers_bytes.head/.tail.

[D8] Character literals: Char.to_u32('\u{D800}') etc. become
  U32_of_N 0xD800 (hex N literals), and Char.to_u32('\u{FFFD}') becomes
  U32_of_N 0xFFFD.

[D9] Section headers: Bend `###` -> (** * ... *), `##` -> (** ** ... *).
  A header comment at the top of the file explains the conventions; a
  comment at the old "all_bytes" location says why it is absent.

[D10] is_unicode_scalar keeps the vacuous lower-bound test
  U32_is_ge cp (U32_of_N 0x000000), as in the original.

======================================================================
5. NOTES ON LAWS.bend (not fixed, reported)
======================================================================

- utf8_decode_buffer_safe quantifies `rest` over all U32 lists with no
  all_bytes condition, while utf8_decode_buffer_prompt requires
  all_bytes(rest).  In Bend the safe law therefore also covers
  continuations with values > 255 (a slightly stronger law).  With the
  native byte type the asymmetry disappears; the Rocq safe law only
  covers byte continuations.  Since a value > 255 can never extend a
  valid sequence prefix, this should not change what decoders satisfy it.
- maximal_subpart is meaningful only for bytes that do not begin with a
  valid sequence (as its comment says); it is only used under
  no_valid_sequence, so this is not a gap.
- Bend literal semantics above 2^32 are not exercised; U32_of_N wraps
  modulo 2^32, and every literal in the file is below 2^32.
