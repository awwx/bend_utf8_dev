    - output: decoded_scalar, decodeBuffer_out_scalar, decodeDone_out_scalar
      (every output code point is a Unicode scalar; U+FFFD included), so the
      output is UTF-16-encodable without surrogate problems.

  RefDecoder design (Utf8Ref.lean, unchanged since first definition):
    State := List UInt8, the pending bytes: [] or a valid-sequence prefix that
    is not a whole valid sequence (1..3 bytes).  step p b looks at p ++ [b]:
    whole valid sequence -> emit cpOf and reset; still a prefix -> keep it;
    otherwise emit U+FFFD (for p, or for b alone when p = []) and, when p was
    non-empty, reprocess b from the empty state (stepFresh).
    decode_buffer = List.foldl stepAcc (s, []) ; decode_done = [] or [U+FFFD].
  Evaluation sanity test: Utf8Eval.lean (all decodes_examples cases plus one
  more, each under every two-way split, byte-by-byte and with empty buffers).

NOT PROVED
  Nothing in the brief is left unproved.

CAVEATS
  - The state is a List; a Wasm/Rust implementation will likely keep the
    pending bytes packed (e.g. a count plus up to 3 bytes, or a partial code
    point + expected length).  Its refinement relation must map to this List.
    The pending bytes are always a prefix accepted by isVSP (Pending).
  - Check time (improvement pass 2026-11-11, see IMPROVEMENT.txt): about
    6-7 s wall per toolchain for the whole layer (was ~57-60 s); check.sh
    about 14 s in total.  No raised maxHeartbeats.
  - A first version used bv_decide (allowed by the brief); it worked but each
    call adds a native-code axiom (`*._native.bv_decide.ax_*`).  It was
    replaced by omega/decide proofs; check.sh now rejects bv_decide and any
    axiom other than propext / Classical.choice / Quot.sound.

NEXT STEPS (if continued)
  - encodes_of_isVS / isVS_of_encodes are the slowest proofs left (~2 s CPU
    each); a per-lead-class form of secondOk would shorten and speed them.
  - cpOf_one..four: a single `x * 2^k ||| y = x * 2^k + y` simp lemma
    would replace the rw chains (statements must stay; Aeneas uses them).
  - Optionally add an alternative state representation (e.g. needed-count +
    accumulated code point + lower/upper bound for the next byte, as in the
    Unicode/Hoehrmann DFA style) proved equivalent to State := List UInt8,
    if the downstream artifacts prefer that.
  - Lemmas giving the step result directly in byte-range terms
    (e.g. "p = [], b in C2..DF -> step p b = ([b], [])") if downstream proofs
    want to avoid unfolding isVS/isVSP.
