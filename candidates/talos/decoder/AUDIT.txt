  The claim holds, with caveats that concern presentation and the check script, not the
  proof. Utf8Wasm.shippedModuleCorrect has exactly the type Utf8Boundary.ShippedModuleCorrect,
  depends on [propext, Classical.choice, Quot.sound] only, and a full kernel replay of every
  non-core constant (Talos + candidate, 11,632 constants) is accepted. Every one of 12
  semantic mutations of decoder.wat makes the proof fail; the 2^32 edge is handled correctly
  and is harmless for the shipped wrapper. check.sh passes from a clean copy (2 min 07 s).

  What a user may rely on (within Talos's semantics, for the module Talos decodes from the
  printed text of the shipped bytes): starting from any memory (any contents, any page
  count <= 65536) and otherwise the module's initial store,
  - decode_start_state returns a value related to D.start and changes nothing;
  - decode_buffer(v, inp, len, out) with v related to s, inp + len <= out and
    out + 8*len <= memory size: reaches a normal return (Talos Step is deterministic, so no
    trap, no stuck state, no divergence), returns (v', end) with v' related to s',
    end = (out + 4|t|) mod 2^32, |t| <= 2*len, [out, out+4|t|) holds t as u32le, every other
    byte and the page count unchanged, and nothing else in the store changed;
    (s', t) = D.decode_buffer s (the len input bytes);
  - decode_done likewise with out + 4 <= memory size, |t| <= 1;
  for one D with D.Correct (utf8_decodes, utf8_decode_buffer_safe, utf8_decode_buffer_prompt,
  unmodified spec). Since every call ends in storeWith m mem' and the hypotheses quantify over
  all memories, this covers call N+1 on the memory left by call N, including the wrapper's
  writes to the input area in between.

2. BOUNDARY.LEAN AS A HOSTILE REVIEWER
  - D is existential but pinned by D.Correct (the unmodified spec, hash-pinned). R is
    existential, but StartOk forces R D.start (start value) and BufferOk forces R s' v' for
    the returned value, so every state the wrapper can hold is related to a reachable D
    state, and Correct fixes D's per-call text along every feed from D.start (safe + prompt
    determine each call's output; utf8_decodes fixes decode_done). A degenerate R (empty)
    fails StartOk; a degenerate D fails Correct. If R relates one value to several states,
    BufferOk must hold for all of them (stronger, not weaker). No vacuity apart from M2.
  - "Runs": Calls = Talos RunsExportWith = startExportConfig? succeeds (export exists,
    argument count/types match) and ∃ finite Steps trace to .done values. Not partial
    correctness. Talos proves Step deterministic (step_deterministic, steps_comparable,
    safe_of_steps_to_done; axioms standard, checked), so a done trace excludes trap, stuck
    (internal error) and divergence. The determinism theorem is not used by the proof but is
    what gives "terminates without trapping" its meaning; it is proved in Talos, not assumed.
  - Postconditions: returned values exactly [v', ofNat(out + 4|t|)]; bytesAt mem' out 4|t| =
    textBytes t (u32le); sameOutside = same page count and same bytes outside the written
    range; final = storeWith m mem' (whole store, so no other component changes). This is
    "nothing else changed", and it is stated, not implied. |t| <= 2 len and |t| <= 1 are
    stated.
  - Hypotheses vs the wrapper: wrapper uses inp = 0, len <= 2^20, out = 2^20, module memory
    160 pages (10 MiB, never grown): 0 + len <= 2^20 and 2^20 + 8*2^20 = 9 MiB <= 10 MiB;
    decode_done out + 4 <= 10 MiB. No alignment is required (Talos has none; out is 4-aligned
    anyway). Satisfied on every call.
  - 2^32 edge: BufferLayout allows out + 8 len = 2^32 only with 65536 pages. Written bytes
    lie below out + 4|t| <= 2^32, so no store address wraps; the end pointer wraps to 0 when
    out + 4|t| = 2^32, and the statement says exactly that (UInt32.ofNat). True as written
    and proved (writeCps_*, endAddr_eq). Not a hole: a caller computing (end - out) mod 2^32
    still gets 4|t|; only a caller that reads end as an absolute address with end < out would
    misread it, and the shipped wrapper's end is at most 9 MiB, nowhere near the edge.
  - Chain bytes -> Module:
      decoder.wasm --(wasm-tools print, TRUSTED)--> text
      text == decoder.printed.wat               CHECKED (cmp in check.sh)
      decoder.wasm == strip(parse(decoder.wat)) CHECKED (not needed for soundness; the wat
                                                source and `parse` are not trusted)
      printed.wat --include_str--> Boundary.printedWat; == Utf8Wasm.printedWat (rfl, CHECKED)
      Talos decodeForVerification on that string = .ok decoderModule: kernel-evaluated
        (cbv, CHECKED); that this parser implements the WAT text format: TRUSTED
      decoderModule --Talos Step semantics--> theorem: semantics vs Wasm spec / V8 TRUSTED
    Validation is outside the theorem (wasm-tools validate runs in check.sh; V8 validates at
    instantiate).
