PROVED (no sorry, axioms propext / Classical.choice / Quot.sound; see Axioms.lean)
  - decoderModule_decodes: Talos's decodeForVerification on the printed text of
    the shipped bytes = the literal `decoderModule` (kernel `cbv`).
  - start_ok: decode_start_state returns 0 (= enc []), store unchanged.  This is
    already exactly Boundary's StartOk shape with R := Rel.
  - done_runs: decode_done(v, out): v = 0 -> returns out, store unchanged;
    v != 0 -> writes 0xFFFD (write32) at out, returns 4 + out.
  - buffer_runs: decode_buffer(v, inp, len, out), under the layout contract
    (plus out + 8*len < 2^32), terminates without trapping and returns
    (runM ...).1 / .2.1 with final store storeWith (runM ...).2.2, where runM is
    a Wasm-level model: a left fold over bytesAt mem inp len of stepM.
  - Call lemmas (any caller context) for every function: call_cont,
    call_second, call_vs, call_vsp, call_cp (pure helpers, against Bool/UInt32
    models contB, secondB, vsB, vspB, cpV), call_step0 / call_step ($step with
    its memory writes, against stepM / writeCps / endAddr), loop_correct.
  - stepM_nil (ProofModel.lean): the per-byte refinement for the empty-pending
    case:  stepM 0 x.toUInt32 = (enc (step [] x).1, (step [] x).2).
    Also in ProofModel.lean: or_shl_toNat (packing as a Nat sum), bytes_of_toNat
    (by1..by4 extract the bytes of a packed word), contB_eq (= isCont),
    secondB_eq (= secondOk): the byte-level lemmas the other cases need.
  - Imported unmodified: Utf8Pure.RefDecoder_correct.

NOT PROVED (exact missing statements)
  1. Model refinement (pure, no Wasm):
       for p : List UInt8 with 1 <= p.length <= 3 and b : UInt8 (p = [] is done),
         stepM (enc p) b.toUInt32 = (enc (step p b).1, (step p b).2)
       and (step p b).1.length <= 3.
     Still needs: (qOf (enc p) b).toNat and (enc p).toNat as Nat sums (from
     or_shl_toNat), nOf (enc p) = p.length, the new-state equation
     q ||| (m <<< 24) = enc (p ++ [b]), and vsB/vspB/cpV of a packed word =
     isVS/isVSP/cpOf for lengths 2..4 (bytes_of_toNat + secondB_eq + contB_eq
     reduce these to Bool goals over byte ranges, which still need closing);
     then the case analysis of step as in stepM_nil.
  2. runM v out mem bs = (enc s', endAddr out t, writeCps mem out t) where
     (s', t) = decodeBuffer s bs and v = enc s  (induction using 1);
     endAddr out t = ofNat (out + 4*|t|) (have endAddr_toNat);
     bytesAt (writeCps mem out t) out (4*|t|) = textBytes t and
     sameOutside mem (writeCps mem out t) out (4*|t|)  (write32 lemmas);
     t.length <= 2 * bs.length  (from stepM_len, already proved).
  3. decode_done: enc s = 0 <-> s = [] (enc_eq_zero, proved) and the write32 layout
     lemma, to get DoneOk.
  4. Assembly: Realizes decoderModule RefDecoder with R := Rel, the 2^32 edge case
     (see above), then ShippedModuleCorrect by rewriting with
     decoderModule_decodes and RefDecoder_correct.
