  The 2^32 edge (resolved, statement proved as written): BufferLayout allows the
  output area [out, out + 8*len) to end exactly at 2^32 (only with 65536 pages).
  The statement is TRUE there and is proved as written.  Reason: every byte
  written lies below out + 4*|t| <= 2^32, so no store address wraps; only the
  pointer after the last code point can wrap (to 0), and Boundary states the
  returned end as UInt32.ofNat (out + 4*|t|), which wraps identically
  (endAddr_eq).  The first session's loop proof needed out + 8*len < 2^32 only
  because it computed the end pointer's toNat after the last byte; loop_correct
  now handles the last byte separately, and that hypothesis was removed from
  loop_correct and buffer_runs (a strengthening; check.expected.txt updated).
  decode_done at out = 2^32 - 4 is covered the same way.
